'@quantajs/lit': minor

New package: Lit bindings. `QuantaValueController`, `QuantaController`, `QuantaActionsController` and `QuantaLocalController` connect stores to web components through Lit's reactive controllers, for Lit 2 and 3. `provideQuantaContainer()` scopes an element's subtree to a container using the web components context protocol, so `@lit/context` providers work too.
